# BEES Health

A polished safety-first visit companion prototype. It demonstrates dual consent, live recording state, evidence-linked clinical claims, an accessible AI draft, clinician confirmation, recipient-bound sharing, patient-approved reminders and a confirmed-only FHIR document adapter.

Run `npm install`, then `npm start` and open `http://localhost:4203`. Run `npm test` for the safety-state tests and `npm run test:e2e` for the desktop/iPhone/Android browser simulations.

All demo data is synthetic. BEES Health is not medical advice, diagnosis, emergency support, an EHR source of truth, or a cleared medical device.

See `docs/POSTVISIT_AND_ACCURACY.md` and `docs/PLATFORM_ARCHITECTURE.md` for the safety/evaluation approach and deployment surfaces.

Development resumes from `docs/WORK_STATUS.md`. Credential onboarding is documented in `docs/SETUP_AND_CREDENTIALS.md`; secrets must never be committed or pasted into chat.
